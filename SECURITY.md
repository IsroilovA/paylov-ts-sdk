# Security policy

## Supported versions

Only the latest published version of `@isroilov_an/paylov` receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/IsroilovA/paylov-ts-sdk/security/advisories/new),
not in public issues or pull requests.

- Describe the affected version, the impact, and steps to reproduce.
- Never include real credentials, tokens, card numbers, or personal data; use placeholders.
- Expect an acknowledgement within 7 days. Fixes are released as a new version and disclosed in a
  GitHub security advisory once published.

## Scope

This policy covers the SDK in this repository. Report vulnerabilities in the Paylov gateway or its
dashboard to Paylov directly; this project is not affiliated with Paylov.
