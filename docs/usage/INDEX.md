# @isroilov_an/paylov usage

Guides for the server-side Paylov SDK: integration flows and pitfalls. Method contracts live in the
JSDoc, fields in the types. Start with [setup.md](setup.md).

Import from `'@isroilov_an/paylov'`, and test helpers from `'@isroilov_an/paylov/testing'`. Examples
call `paylov`, the client from [setup.md](setup.md).
