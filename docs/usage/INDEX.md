# @isroilov_an/paylov usage

Guides for the server-side Paylov SDK: integration flows and pitfalls. Method contracts live in the
JSDoc, fields in the types. Start with [setup.md](setup.md).

Import from `'@isroilov_an/paylov'`, and test helpers from `'@isroilov_an/paylov/testing'`. Examples
call `paylov`, the client from [setup.md](setup.md).

## Surface map

| Export / method                                                                                                                                                                               | Purpose                                                                         | Doc                                    |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------- |
| `new PaylovClient(config)` — `close`                                                                                                                                                          | One long-lived client per credential set per process                            | [setup.md](setup.md)                   |
| `paylov.gateway` — `getStatus`, `listBanks`                                                                                                                                                   | Liveness probe; issuing banks                                                   | [setup.md](setup.md)                   |
| `config.fetch`, `config.logger` (`PaylovLogger`), `config.maxGetRetries`, `config.now`                                                                                                        | Proxy `fetch`; metadata-only observability; GET retries; clock                  | [setup.md](setup.md)                   |
| `PaylovError`, `PaylovInputError`, `PaylovClientClosedError`, `PaylovApiError`, `PaylovProtocolError`, `PaylovConnectionError`, `isPaylovError`, `isPaylovApiError`, `isPaylovOutcomeUnknown` | Branch on failures; recover after an ambiguous one                              | [errors.md](errors.md)                 |
| `sumToTiyin`, `formatSum`                                                                                                                                                                     | Money units, wire units and time zones                                          | [money-and-time.md](money-and-time.md) |
| `paylov.cards` — `createBindLink`, `getBindSession`, `startPanBinding`, `confirmPanBinding`, `get`, `list`, `delete`, `checkPhone`                                                            | Bind cards (hosted Card Bind or PAN + OTP), read and remove them                | [cards.md](cards.md)                   |
| `paylov.payments` — `create`, `pay`, `refund`, `startPanPayment`, `confirmPanPayment`                                                                                                         | Charge a saved card or a one-off card number; full refund                       | [payments.md](payments.md)             |
